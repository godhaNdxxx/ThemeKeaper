===========================================================
  ThemeKeeper — Защита MTZ-темы от отката HyperOS
  Инструкция по сборке APK
===========================================================

ТРЕБОВАНИЯ:
- Android Studio Ladybug (2024.2+) или новее
- JDK 17+
- Android SDK 35

СБОРКА:
1. Откройте папку ThemeKeeper в Android Studio
   (File → Open → выберите папку ThemeKeeper)

2. Дождитесь синхронизации Gradle (может занять 2-3 минуты)

3. Соберите APK:
   Build → Build Bundle(s) / APK(s) → Build APK(s)

4. APK будет в:
   app/build/outputs/apk/debug/app-debug.apk

УСТАНОВКА НА ТЕЛЕФОН:
1. Скопируйте app-debug.apk на POCO X6 Pro
2. Откройте файл и установите (разрешите установку из неизвестных источников)

ИСПОЛЬЗОВАНИЕ:
1. Запустите Shizuku на телефоне (через Wireless Debugging)
2. Откройте ThemeKeeper
3. Дайте разрешение Shizuku (кнопка в приложении)
4. Примените вашу MTZ-тему через ChaoMe Theme Editor
5. В ThemeKeeper нажмите "Зафиксировать" — приложение сохранит параметры темы
6. Нажмите "Запустить защиту" — фоновый сервис начнёт мониторинг
7. Нажмите "Оптимизация" чтобы отключить оптимизацию батареи для приложения

ПОСЛЕ ПЕРЕЗАГРУЗКИ:
- Shizuku нужно перезапустить (если не настроен автозапуск)
- ThemeKeeper автоматически запустит защиту при загрузке
  (но работать она начнёт только после запуска Shizuku)

АРХИТЕКТУРА:
- ShizukuHelper.kt    — выполнение shell-команд через Shizuku (ADB-уровень)
- ThemeSnapshot.kt    — захват/восстановление параметров темы из Settings
- ThemeMonitorService — foreground-сервис с ContentObserver + polling
- BootReceiver        — автозапуск после перезагрузки
- MainActivity        — UI управления

КАК РАБОТАЕТ:
1. При фиксации — сканирует ВСЕ настройки системы связанные с темой
   (settings list secure/system/global | grep theme)
2. Сохраняет их как "желаемое состояние"
3. Фоновый сервис мониторит изменения двумя способами:
   a) ContentObserver на Settings.Secure/System — реактивно
   b) Polling каждые 15 секунд — как fallback
4. При обнаружении отката — восстанавливает все параметры через
   "settings put" команды с ADB-привилегиями Shizuku
